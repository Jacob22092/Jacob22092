# Security Policy

This repository hosts a personal/business profile README with no executable
application code, so the attack surface is minimal. If you nonetheless spot a
security issue related to this repository (e.g. a leaked secret or a
malicious link), please report it privately instead of opening a public issue.

## Reporting

- Email: [kontakt@jhyziak.eu](mailto:kontakt@jhyziak.eu)

Please include a description of the issue and steps to reproduce it if
applicable. Reports are acknowledged as soon as possible.
